"expense tracker application", sẽ build cả Frontend và Backend, sẽ làm backend trước.
Bây giờ thay vì giao hoàn toàn 1 đề tài mà để cho làm thì lan man, thì lần ni a2 sẽ bày theo từng phase, và hãy để tâm cách làm từ 1 dự án nó như thế nào.

Chức năng đơn giản và cơ bản:
1. Sign up/sign in as a new user - Phải dùng Generate and validate JWTs for handling authentication and user session.
2.CRUD expense.
3. Về expense, nghĩa là thu/chi, thu thì thu từ đâu, chi thì chi ra nguồn nào.

Tại sprint 1:
1. Thiết kế Database model, ban đầu cứ dùng Json file làm db.
2. Build API về CRUD expense
3. Setup SwaggerAPI.
Note:
- Ở sprint ni chưa cần sử dụng các db lớn, JWT
- Nên lựa chọn ExpressJs để build API trước, hiểu về kiến trúc một folder code Backend.
